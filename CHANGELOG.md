## 1.0.0

- Establishes the first versioned Genux package baseline for reusable Flutter
  UI primitives, including form controls, navigation, layout, and display
  components.
- Includes the Material Symbols Outlined variable font as a package asset, with
  its Apache 2.0 license and source information. Consumers may use it through
  Flutter's icon APIs without adopting Material widgets.
- Includes A2UI catalog definitions and an experimental static JSON preview.
  The static preview has no compatibility guarantee and is not an A2UI runtime.
- Requires Dart 3.13 or later within the Dart 3 SDK and Flutter 3.50 or later.
